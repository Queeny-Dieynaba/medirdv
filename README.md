# MédiRDV - Clinique Les Baobabs

Plateforme de gestion, de planification et d'analyse des rendez-vous médicaux[cite: 1].

## 📋 Description du Projet
Développé dans le cadre du projet de Licence 3 (Science des Données), MédiRDV centralise la prise de rendez-vous des 9 spécialités de la Clinique Les Baobabs à Dakar, élimine les doubles réservations et fournit des indicateurs de pilotage à la direction[cite: 1, 3, 4, 5].
